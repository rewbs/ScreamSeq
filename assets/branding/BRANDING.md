# ScreamSeq artwork

`ScreamSeq.png` is the application icon, generated with the built-in image-generation tool from the user-supplied `splash-reference.png`. The source reference is retained unchanged. `mac/Tools/Icon.swift` packages it into native icon sizes without altering the artwork. Windows can derive an ICO from this same source.

Generation prompt:

> Use case: logo-brand. Create one polished application icon for ScreamSeq, a fast native tracker DAW. The attached image is the visual reference: a horizontally symmetrical, organic neon waveform/squid-like spectral form, broad cyan teardrop center pointing right, purple and magenta body, curling flame tendrils and warm yellow/green outer tips. Develop a distinctive simplified logo based closely on this silhouette and spectral palette. Remove the reference's white chart background, all grid lines and axes. Make the mark bold enough to read at Dock icon sizes, retaining a few deliberate flowing tendrils rather than excessive hairlines. Present a single centered mark inside a deep near-black navy rounded-square macOS app icon tile with restrained dimensional polish, generous safe margin, crisp edges and balanced optical weight. Straight-on orthographic app artwork only, no physical mockup, no text, no letters, no music-note symbol, no extraneous decorations. Square high-resolution output; genuine transparent corners outside the rounded tile. This is a new project asset derived from the reference, not a literal screenshot cleanup.

The product name, app menu, executable, icon and new project extension are ScreamSeq. Legacy `org.resonance` bundle/document identifiers, built-in plugin class IDs, cache/recovery locations, API discovery directory and clipboard/preset magic remain stable compatibility identifiers. Existing `.resonance` projects and `.resonance-preset` files are supported; new Save As operations use `.screamseq` and `.screamseq-preset`. Do not globally replace persisted identifiers when editing branding.
